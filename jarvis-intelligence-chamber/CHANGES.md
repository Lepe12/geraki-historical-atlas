# NABOU//X — Ναυτική διεπαφή στη διάταξη του mockup (THEATRUM · MARIS · MEDITERRANEI)

Η σελίδα `jarvis-intelligence-chamber/` έχει πλέον τη διάταξη του εγκεκριμένου mockup. Όλα όσα εμφανίζει τροφοδοτούνται από την **πραγματική** λειτουργικότητα και τα **πραγματικά** δεδομένα. Δεν υπάρχουν δοκιμαστικά δεδομένα.

Τα κουμπιά και οι ετικέτες της διεπαφής είναι στα αγγλικά, όπως στο mockup. Το περιεχόμενο και τα μηνύματα μένουν ελληνικά.

## Διάταξη
- **Επιφάνεια εργασίας:**
  - Σταθερός «πίνακας» 1672×941 που κλιμακώνεται στο παράθυρο, όπως το mockup.
  - Επάνω μπάρα: SEARCH, RESEARCH, LEARNING, ARCHIVES, AGENTS, EVIDENCE, MAP, ημερομηνία/ώρα και πυξίδα.
  - Αριστερή στήλη: OPERATOR, TARGETS, AGENTS, SOURCES, LEARNING, EVIDENCE, MAP LAYERS, SETTINGS και ο αστρολάβος «Mediterranean Historical Theater».
  - Λίστα HISTORY / TERRITORY / PEOPLE / INTELLIGENCE και η κορδέλα THEATRUM · MARIS · MEDITERRANEI.
  - Το πλαίσιο OPERATOR QUERY με σφραγίδα αποστολής και φίλτρα.
  - Ο κορνιζαρισμένος πορτολάνος στο κέντρο.
  - Κάρτες PLACES / EVENTS / PEOPLE / SOURCES.
  - Δεξιά στήλη: γαλέρα «NABOU//X», SYSTEM STATUS, RECENT ACTIVITY και ACTIVE NODES.
- **Κινητό (≤ 800px):** στοιβαγμένη διάταξη.
  - Σταθερή επάνω μπάρα και γραμμή ενοτήτων.
  - Κάτω, σταθερό πλαίσιο ερωτήματος με τα φίλτρα.
  - Ο χάρτης, οι κάρτες και οι στήλες κατάστασης εμφανίζονται με κύλιση.

## Τι συνδέεται με τι

| Στοιχείο του mockup | Πραγματική λειτουργία / δεδομένα |
|---|---|
| OPERATOR QUERY + σφραγίδα | Αποστολή νέας έρευνας (`/dispatch`, ίδιος κώδικας). Το placeholder δείχνει το ερώτημα της τρέχουσας έρευνας. |
| Φίλτρο περιόδου | Το API δέχεται μόνο κείμενο, οπότε η περίοδος **προστίθεται στο ερώτημα** όταν σταλεί, π.χ. «… (1600–1700)». |
| Φίλτρο πηγών | Τα πραγματικά αποθετήρια της τρέχουσας έρευνας (με πλήθος). Η επιλογή φιλτράρει τα ευρήματα μέσω της υπάρχουσας αναζήτησης. |
| Φίλτρο τεκμηρίων | Όλα / Ισχυρισμοί / Αντιφάσεις / Εμπόδια: τα υπάρχοντα φίλτρα αποτελεσμάτων. |
| Ταξινόμηση | Η υπάρχουσα ταξινόμηση (συνάφεια, αξία, ωριμότητα, έτος). |
| Advanced | Ταξινόμηση, εξαγωγή JSON/CSV/CSL/BibTeX και άνοιγμα με αριθμό έρευνας. |
| Χάρτης | Οι 17 σφραγίδες στις θέσεις των αρχείων, με τις ίδιες καταστάσεις, ευρήματα και εμπόδια, και με μετακίνηση/ζουμ. |
| SEARCH / OPERATOR | Χάρτης και πλαίσιο ερωτήματος. |
| RESEARCH | Ο φάκελος της έρευνας. |
| EVIDENCE | Τα ευρήματα και οι πηγές. |
| PEOPLE | Οι ισχυρισμοί. |
| AGENTS | Η λίστα των ερευνητών. |
| ARCHIVES / SOURCES / PLACES | Οι ερευνητές με το φίλτρο «Αρχεία». |
| INTELLIGENCE | Οι ερευνητές με το φίλτρο «Ανάλυση». |
| LEARNING | Ο έλεγχος PDF (τοπική ανάλυση και αποστολή, όπως πριν). |
| TARGETS / HISTORY | Οι προηγούμενες έρευνες, με αναζήτηση και `?run=`. |
| EVENTS | Ο πίνακας «Πορεία». |
| MAP LAYERS | Επίπεδα του χάρτη: σφραγίδες, ονόματα, διαδρομές, ρόμβοι, τοπωνύμια, εικόνες. |
| SETTINGS | Κατάσταση σύνδεσης, χωρίς κινήσεις, πιο πρόσφατη έρευνα, επαναφορά χάρτη. |
| Πυξίδα / αστρολάβος | Επαναφορά του χάρτη. Ο αστρολάβος δείχνει και την κατάσταση της έρευνας και τα εμπόδια. |
| SYSTEM STATUS | **AGENTS**: ολοκληρωμένοι (και ενεργοί) / σύνολο. **SOURCES**: αποθετήρια που ερωτήθηκαν· η μπάρα δείχνει την αναλογία με αποτελέσματα. **RECORDS**: καταγεγραμμένες πηγές + ισχυρισμοί. **CONFLICTS**: καταγεγραμμένες αντιφάσεις. Αν δεν έχει φορτωθεί έρευνα: «—». |
| RECENT ACTIVITY | Τα 5 πιο πρόσφατα συμβάντα ερευνητών (από το snapshot και τα ζωντανά events). Το «Πορεία» ανοίγει όλη τη ροή. |
| ACTIVE NODES | Μικρός χάρτης με τους 17 ερευνητές, χρωματισμένους ανά κατάσταση· το κλικ ανοίγει τους ερευνητές. |
| PLACES / EVENTS / PEOPLE / SOURCES | Πλήθος: 11 αρχεία / συμβάντα / σχετικές αναφορές / διαφορετικές πηγές. Ανοίγουν τις αντίστοιχες προβολές. |

## Αμετάβλητα
- Η ζωντανή σύνδεση (WebSocket, polling 15″, εφεδρικό raw.githubusercontent) και τα endpoints. Το γνωστό διπλό fetch του εφεδρικού αρχείου **δεν** διορθώθηκε.
- Οι ερευνητές, η καρτέλα ερευνητή, ο φάκελος, τα ευρήματα (φίλτρα, αναζήτηση, ταξινόμηση, σελίδες), οι λεπτομέρειες και οι σύνδεσμοι πηγών, το ιστορικό, το `?run=`, η εξαγωγή, η αποστολή, το PDF, το Esc και τα ελληνικά μηνύματα, όπως αυτά για μη έγκυρο ή άγνωστο αριθμό έρευνας.

## Περιορισμοί και ειλικρινή κενά
- Δεν υπάρχει ξεχωριστό API για περίοδο, θέμα ή τύπο οντότητας. Γι' αυτό η περίοδος προστίθεται στο κείμενο του ερωτήματος, και τα άλλα δύο φίλτρα του mockup αντιστοιχούν στο είδος τεκμηρίου και στην ταξινόμηση.
- Τα ευρήματα δεν έχουν συντεταγμένες, οπότε στον χάρτη εμφανίζονται μόνο οι 17 ερευνητές.
- Οι μπάρες στο SYSTEM STATUS είναι αναλογίες, όπου υπάρχει παρονομαστής. Για RECORDS και CONFLICTS δείχνουν λογαριθμική ένταση.
