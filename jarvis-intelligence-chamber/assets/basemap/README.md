# Zoomed-in relief basemap

Tiles `{z}/{x}/{y}.webp` (Web Mercator, 256 px; z7 and z8 over the chart window lon −20…40, lat 28.4…55.2).

Source: NASA Earth Observatory, *Blue Marble: Shaded Relief and Bathymetry* (public domain, NASA open data
policy), via the FreeTiler tile set. Restyled for NABOU by `tools/atlas/build_relief_tiles.py`: land and sea
recoloured to the overview chart's sepia and sea green, land/sea split from Natural Earth 1:10m (public domain)
where available. Credit: "Relief: NASA Earth Observatory (Blue Marble)".
