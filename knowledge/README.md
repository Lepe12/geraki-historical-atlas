# Κοινή μνήμη έρευνας

Το `pirates_bases.md` είναι κοινή μνήμη για τους research agents. Περιλαμβάνει διορθώσεις του ιστορικού, παλιά ονόματα τόπων, ευρήματα με πηγές, μαθήματα διαδικασίας (τι δούλεψε/τι απέτυχε) και ποιότητα πηγών.

Οι agents πρέπει να το διαβάζουν πριν από κάθε έρευνα και να προσθέτουν τις νέες τεκμηριωμένες γνώσεις μετά. Δεν επινοούμε τίποτα· οι διορθώσεις του ιστορικού υπερισχύουν.
