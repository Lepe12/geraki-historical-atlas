# N7 figure conversation without a password

Owner instruction: remove the password requirement from using the figure. The preview now exposes its microphone, voice test and message composer without login. Exiting/reopening and the preview workspace also do not show password fields. Existing authenticated N7 sessions continue using their existing conversation transport.

An unauthenticated visitor uses the dedicated stateless `/api/n7-apex/chat` route and existing configured model. No fake response, embedded password, owner token, automatic owner login or new paid provider is used. The visitor's short context stays in browser memory and accompanies the next message; it is not written into the owner's stored conversations. Private files, history, tools and Agents are not exposed. This is a public figure conversation, not password removal from the owner's private administration API.

The additive backend module has its own public status at `/api/n7-apex/status`. It accepts only same-origin JSON with bounded user/assistant messages, never supplied system/tool roles; fixes output limits, two concurrent model calls, six requests per minute per network address and sixty per hour globally; does not retry automatically. API credentials stay on the existing server. Model errors are sanitized. No owner data modules or tools are loaded by the public module.

Deployment reads private server source only in ephemeral CI memory, recognizes one HTTP server callback and the existing provider bindings, inserts the separate handler before the unchanged original handler body and retains the existing relay/authentication unchanged. It syntax-checks before writing, detects concurrent changes, stages and verifies exact bytes, retains private backups, restarts Passenger and rolls back on failed health/model/auth checks. The existing canonical base runtime receipt is not rewritten to misrepresent a new canonical source build; this is an additive overlay with before/after server hashes recorded in deployment logs. Future canonical reconciliation must retain this overlay if passwordless figure chat is desired. Production `/n7-apex/` static assets remain untouched.
