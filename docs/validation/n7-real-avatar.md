# Real rigged N7 avatar trial

The owner approved proceeding with the GitHub/MPFB real-3D route. `/n7-apex-step5/avatar-3d/` now uses the actual CC0 volumetric GLB, one 67-joint skin and 22 retained viseme/blink/jaw/expression morphs. There is no front-image plane or old head behind it. `GLTFLoader` uses the existing Three.js 0.184 renderer; no global engine migration or separate paid voice/AI service. Source TalkingHead model/CC0 provenance and original SHA are recorded in `prepare_real_avatar.py` and `N7-3D-NOTICE.txt`.

The original 36,815,920-byte GLB was reduced to 8,052,020 bytes by retaining useful facial targets, removing unused accessor data and reducing embedded images to 1024-pixel WebP. Vertex geometry, skin, joints and retained morph deltas are preserved. Prepared SHA256 `d3ad956f21033e43a32574fa474ac7d76d9c5d81dac432a5b5b291bea3b9638b` is pinned in the builder. The original 36 MB model is not committed. The 8 MB distributable and CC0 notice are committed, so deployment does not require image tooling or an external model API.

The test view has front, real 90-degree profile, 180-degree rear, mouse-driven head bones, automatic head motion and free orbit. Head/full-body views and an optional blue/gold N7 material treatment are available. Natural source face/hair is the initial view; this is a first real-geometry prototype, not a claim that the stock face/hair exactly match H01. Facial test buttons exercise the actual morphs. Renderer, assets, controls, event listeners and requests are cleaned up on exit. Existing v4/default and production `/n7-apex/` are preserved; the isolated trial link points to real 3D.

The existing Greek Piper voice/microphone hook and public stateless N7 chat route are reused. A single Start performs final recognition → actual request state → reply audio → listening rearm. Stop cancels audio and pending client requests, discards late replies and keeps the avatar visible. Manual text and explicit readback are available. Outgoing Web Audio RMS drives the jaw during playback, including silent pauses; this is amplitude-driven mouth movement, not phoneme-accurate Greek lip synchronization. Viseme shapes remain available for later timed phoneme integration. Reduced motion disables automatic reactions; explicit pose/morph controls remain available.

An initial six-second audio fixture exposed a delayed release on slow software-rendered frames: the shared voice envelope clamped elapsed time to 100 ms. It now uses real elapsed time for audio attack/release, so a low frame rate does not extend a silent pause. The existing v4 face/audio regression passed after this shared change. The new avatar test waits for actual rig readiness, verifies side/rear pixel changes and independent blink/jaw changes at a fixed viewport layout, and verifies actual Web Audio jaw start/pause/Stop, continuous turn-taking and rejection of late replies. API, input-recognition and tone PCM in that suite are explicitly fixtures; geometry, skinning, rendering, morphs and AudioContext are real.

Local optimized build/type/lint and the full new browser suite passed with no browser/shader errors. Source-pinned meshes: 8, bones: 67, useful morphs: 22. Mobile layout passed; existing face audio-effect regression passed. See `n7-real-avatar-evidence/`. Live deployment/real-model/real-Greek-speech checks are separate stages and must be recorded after completion.
