# Embedded Greek female voice

Live verification (2026-11-11): workflow [43086849184](https://github.com/Lepe12/geraki-historical-atlas/actions/runs/43086849184) passed validation and deployment. The isolated preview release is `63fb7bf188c9afc4`; production remains `bbdc05016a211581`. A fresh browser loaded the deployed Greek model and generated/played non-silent speech with zero native voice calls: cold start 45.21 s, duration 3.488 s, RMS 0.03340, peak 0.42362. Stop, automatic recognition rearm and reload cache reuse passed with no browser errors. These live tests used controlled recognition/API fixtures; physical laptop speakers and microphone were not tested. See `n7-female-voice-evidence/live-results.json` and `live-greek-female-sample.wav`. A separate full download of the live model matched the pinned SHA256 `7824cd5c9912e8aab9fce653f7af9d609c4e2e1d6e4c81d823699afa6d1b1537`.

User request: a female voice speaking Greek independently of the laptop's installed voices. The new default option is **N7 · Ελληνική γυναικεία** (`n7:el-female`), using Piper `el_GR-rapunzelina-low`, a Greek single-speaker female voice. This is local browser synthesis through a dedicated Worker, ONNX Runtime Web 1.18.0 and the Piper/eSpeak phonemizer. No new paid API, subscription, credential, owner session or server inference is introduced. The existing native device voices remain explicit selectable alternatives.

The Greek model and runtime are pinned by SHA256 and reconstructed from the public Sherpa-ONNX voice release and fixed npm package versions. A separate immutable public `n7-apex-voice/rapunzelina-v1` bundle prevents every UI export from uploading the large weights again. First use downloads about 90 MB; the model/phonemizer data are cached in browser Cache Storage, and the loaded session is reused. No user text or generated audio is cached by this feature or sent to a speech provider. The model card states Greek/16 kHz and CC0 dataset licensing; the published bundle retains the model card, ONNX MIT license, eSpeak GPL copying text, package/source/build links and notices.

The main thread unlocks Web Audio on the initial voice gesture, then decodes generated PCM WAVs and starts AudioBufferSource playback. Speaking follows actual playback start, and automatic listening resumes only after the final playback end plus the existing tail delay. Stop cancels playback/in-flight work; page closure disposes the worker/context. Generation guards discard late results. Errors explicitly pause the conversation; there is no silent switch to a male device voice. The figure, head/camera, chat model, private auth and password-free transport are unchanged by this voice change.
